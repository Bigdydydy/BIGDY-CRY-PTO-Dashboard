# 双视角合成规则

> 一个 agent，两个视角，一个裁决层。
> - 视角 A = [framework.md](framework.md)：美国利率 → 风险资产 → 执行。
> - 视角 B = [brooks_lens.md](brooks_lens.md)：全球利差 → 外汇 → 主权债务。
> - 两人的异同见 [comparison.md](comparison.md)。

## 1. 合并后的分析流程

```
① 事件与定价盘点（共用）
② 定价拆解（共用，必须先做）
   - 利率：名义 = 实际 + 通胀预期；10y10y 远期；期限溢价
   - 政策：Polymarket 概率 vs 美联储指引
   - 商品：油价隐含的供给中断 vs 实际油轮通行量
   - 汇率：汇率 vs 利差（偏离部分 = 风险溢价）
③ 视角 A：央行反应函数 → 财政与流动性 → 增长和通胀 → 盈利和板块 → 情绪和仓位
④ 视角 B：跨国长端比较 → 美元和各国货币 → 主权债务和央行托底 → 商品冲击传导 → EM 分化
⑤ 交叉检验（裁决层）：逐个问题对比两个视角
⑥ 体制判断（R1–R4，视角 B 补充"全球财政主导"和"美元周期"两个维度）
⑦ 交易观点：主题来自任一视角，执行和证伪一律用视角 A 的规则
```

## 2. 主次分工：按问题类型决定以哪个视角为主

| 问题 | 主视角 | 辅助视角 | 原因 |
|---|---|---|---|
| 美债曲线、美联储路径 | A 60% | B 40% | A 有流动性、拍卖和票委分析；B 提供跨国对比和"叙事型美联储"的教训 |
| 美股、板块、AI | A 80% | B 20% | B 基本不分析股票 |
| 美元、G10 汇率 | B 70% | A 30% | B 的利差模型是核心工具；A 提供美元对黄金和风险资产的影响 |
| 新兴市场、亚洲货币 | B 90% | A 10% | A 几乎不涉及 |
| 欧元区、日本主权债 | B 70% | A 30% | A 只在日元和套息交易上有覆盖 |
| 原油、商品冲击 | 50 / 50 | — | A 看通胀传导和柴油，B 看隐含中断和需求弹性；两人分歧较多 |
| 黄金、贵金属 | 50 / 50 | — | A 看实际利率、杠杆资金和央行购金，B 看贬值交易 |
| 日元 | 50 / 50 | — | A 看利差和资金回流，B 看财政和央行托底 |

权重用于组织证据和判断信心，不是机械打分。

## 3. 裁决规则

1. **共识 → 提高信心**：两个视角结论一致时，conviction 上调一级（低→中→高）。
2. **分歧 → 降低仓位，写明裁决数据**：两个视角结论相反时：
   - 正文必须把两边的逻辑都写出来；
   - 指出**能裁决分歧的那个数据或事件**（比如下次 CPI、议息会议、某个利率关键位）；
   - 仓位最多到"少量试仓"；
   - 证伪条件设在裁决点上。
3. **主题要能执行**：来自视角 B 的主题（"美元走弱""EM 分化""贬值交易"）必须配上视角 A 的执行要素：入场区间、200 日线或关键位、可量化的证伪条件。配不上的，只能写成"观察主题"，不能写成交易观点。
4. **战术和结构冲突**：视角 A 的战术观点和视角 B 的结构主题方向相反时，战术观点要缩短持有期、降低仓位，并说明为什么短期逆着结构做。
5. **反夸大要经过仓位确认**：视角 B 说某个叙事过热（比如 200 美元油价），要用视角 A 的情绪和仓位数据确认：叙事极端 **且** 仓位拥挤 → 可以反向；叙事极端但仓位不拥挤 → 先等。
6. **先定价拆解，再给方向**：没有完成第 ② 步就不能给方向判断。
7. **过滤规范性内容**：政策应不应该做（制裁、封锁、欧元存废）不进入市场结论，只保留"如果发生，价格会怎样"。
8. **记录分歧和事后结果**：每期的分歧写进观点台账，事后标注哪个视角对了，作为以后调整权重的依据（参见 comparison.md 第三节的 2026 年案例）。

## 4. 体制判断的补充维度

在 R1–R4（framework.md 第 3 节）之外，再加两个来自视角 B 的维度：

| 维度 | 状态 | 识别信号 |
|---|---|---|
| **全球财政主导** | 无 / 局部（单个国家）/ 全球同步 | G10 的 10y10y 远期是否同时创新高；外围利差；日本央行和欧央行的托底行为 |
| **美元周期** | 利差驱动走弱 / 避险走强 / 鹰派走强 / 区间 | 美元 vs 利差的偏离方向；风险偏好；美联储定价的变化 |

## 5. 已知的系统性偏差

- 视角 A 对美联储偏鹰，2026-09 被证明正确；它对油价和柴油持续高位的判断仍待验证。
- 视角 B 对美联储偏鸽（2026-09 判断失误），对美元偏空（2026-10 时美元仍高于 200 日线），对油价上行风险偏低估还是判断正确，同样待验证。
- 合并时不要把两边的偏差叠加。分歧本身就是不确定性的度量。
