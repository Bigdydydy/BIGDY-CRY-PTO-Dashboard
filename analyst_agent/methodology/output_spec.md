# 评论输出规范

agent 产出的周度宏观评论必须符合本规范。结构参考 2026 年语料中的成熟格式，比如 2026-08-31（5.3%生死线）和 2026-09-08（日元：酝酿历史性反弹）。

## 1. 文章结构

| 段落 | 内容 | 要求 |
|---|---|---|
| 标题 | 一个核心矛盾或关键位 | 例："冰火两世界：债市丧，股市喜""5.3%生死线" |
| 开场（1–2 段） | 本周的反常现象、核心矛盾 | 必须有具体数字 |
| 体制判断（1 句） | 当前属于 R1–R4 中哪种（可以叠加），和上周相比有没有变化 | 见 framework.md 第 3 节 |
| 主线 1：利率 | 利率拆解（实际 + 通胀预期、期限溢价）、曲线形态、央行预期差 | 必须有，除非本周利率确实不是主线 |
| 主线 2–3 | 流动性/财政、盈利/板块、跨资产/地缘，挑本周最重要的 1–2 条 | 每条都要回到"对资产意味着什么" |
| 全球与外汇（视角 B） | 美元 vs 利差、跨国长端（10y10y）、主权债、EM 分化、商品冲击的"定价了什么" | 本周全球侧有变化时必须写 |
| 情绪与仓位 | VIX、MOVE、仓位、拥挤度 | 用于择时判断 |
| **交叉检验** | 表格：问题 / 视角 A / 视角 B / 结论（共识或分歧）/ 裁决数据 | 必须有，至少覆盖本期交易观点涉及的问题；规则见 synthesis.md |
| 复盘 | 上期观点的对照：对了什么、错了什么、证伪条件有没有触发 | 有上期观点时必须写 |
| 情景 | 基准情景 + 小概率情景，带概率 | 概率加起来不要求等于 100%，但要标明哪个是基准 |
| **交易观点** | 按下方第 2 节的表格 | 每条必须带证伪条件 |
| 防线 | 2–3 个最能证伪整体判断的指标和阈值 | 下期复盘要对照 |
| 结尾 | 一句话总结 + 需要同时成立的条件 | — |
| 数据附录 | 正文用到的每个数字：序列 ID、来源、数据日期 | 必须有 |
| 免责声明 | 固定文本，见第 5 节 | 必须有 |

篇幅：正文 2500–4000 字（语料中位数约 6000 字符，含图注）。

## 2. 交易观点格式

每条观点用固定字段，便于以后自动写入观点台账做回测：

```yaml
- asset: 美债30年期            # 资产名
  instrument: DGS30 / TLT      # 观察和执行用的标的
  direction: 战术做多           # 做多 / 做空 / 战术做多 / 减配 / 观望 / 对冲
  horizon: 2-6周               # 时间框架
  entry: 30年期利率 5.30-5.50% 分批  # 入场区间或触发条件
  target: 30年期回到 5.0%        # 目标；没有就写 "无明确目标"
  invalidation: 30年期有效突破 5.5%（连续两个收盘）  # 证伪条件，必填，要可量化
  sizing: 少量试仓               # 少量试仓 / 逐步建仓 / 维持 / 减半 / 清仓
  thesis: 加息落地确认峰值利率；政策工具箱还有余量  # 一句话逻辑
  key_evidence: [UST30Y, REAL10Y, TERM_PREMIUM_10Y, FED_ODDS]  # 依据的指标 ID（indicators.json）
  conviction: 中                # 高 / 中 / 低
  lens_support: both            # esther / brooks / both：哪个视角支持；只有一个视角支持时写明另一个的看法
  dissent: 视角B认为长端上行是全球财政溢价，政策工具压不住  # 有分歧时必填，没有写 无
  decider: 11/4 季度再融资公告的长端发行量  # 有分歧时必填：能裁决分歧的数据或事件
```

规则：

- **证伪条件必须可量化、可观察**：用数据层里有的序列，写明阈值和确认方式（比如"收盘""连续两日""周线"）。
- 证伪价位以**主数据层的收盘值**为准，不用 OpenMarket 永续合约的盘中价。
- 没有把握时可以输出"观望"，但要说明在等什么条件。
- 两个视角有分歧时，sizing 最多是"少量试仓"，证伪条件设在 decider 上。
- 来自视角 B 的主题，如果配不上可量化的入场和证伪条件，只能放进"观察主题"，不能写成交易观点。
- 仓位措辞要克制：用"少量试仓""逐步建仓""不要 All in"，不给具体资金比例。语料里唯一的比例是黄金战略仓位 5–15%，属于长期配置建议。

## 3. 数据引用规则

- 正文里每个数字都必须能在数据附录里找到：`数值 | 序列ID | 来源 | 数据日期`。
- 引用的数据日期距今超过一个更新周期（日频超过 3 个交易日，周频超过 2 周，月频超过 2 个月）时，要标注"数据较旧"。
- 只能写"市场定价""Polymarket 最新成交概率"，不能把概率说成确定结果。
- **禁止编造**：数据层拿不到的数字，要么不写，要么标成"待人工补充"，绝不能估一个看起来合理的数。
- **禁止示意图冒充真实数据**：需要图表时，只能用数据层的真实序列画。
- 引用卖方或媒体观点时注明机构名，不编造具体报告内容。

## 4. 语气

- 第一人称用"我们"或"笔者"均可，但**不得自称 Esther**，也不得暗示内容出自 Esther。
- 多用比较级和历史对比（"自 2022 年 6 月以来最差""35 年新高"）。这类历史对比必须有数据支持，否则不写。
- 判断要明确，但措辞上要留余地：概率 + 条件 + 证伪。

## 5. 固定免责声明

> 本文由 AI 生成，仅供研究与讨论，不构成任何投资建议、要约或招揽。所有观点可能随市场变化而失效，读者应独立判断并自行承担投资风险。文中数据来自公开数据源，可能存在延迟或错误。
