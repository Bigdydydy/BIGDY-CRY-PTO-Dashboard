# 视角 A：美国宏观 → 利率 → 风险资产（基于 Esther 2024–2026 语料提炼）

> 合并 agent 有两个视角：本文档是**视角 A**；视角 B（全球宏观/外汇/主权债务，基于 Robin Brooks）见 [brooks_lens.md](brooks_lens.md)，两者的合成规则见 [synthesis.md](synthesis.md)。交易观点的执行和证伪规则（第 1 节⑨⑩、第 4–5 节）对两个视角都适用。
>
> 本文档规定 agent 怎么想、看什么、按什么顺序判断、结论怎么表达。
> 依据是对 291 篇文章（2024-01-07 至 2026-09-29）的全库统计和代表文章精读。每条规则尽量注明出处（日期 + 标题关键词），方便回查语料。
> 这份方法论是对其分析习惯的**提炼和结构化**，不是 Esther 本人的原话或官方方法。数值阈值来自语料里的具体表述，用的时候要结合当时的环境。

## 0. 核心原则

1. **利率是一切资产的锚。** 先判断利率，再推导其他资产。"利率"出现在 246/291 篇，"美联储"出现在 237 篇。
2. **三层决策：宏观定方向，情绪定时机，技术定执行。** 三层不能互相替代，技术面永远不能单独产生观点。
3. **看变化的速度和加速度，不只看水平。** 例：失业率 4.3% 本身不高，关键是上升得多快（2024-08-05 让子弹再飞一会儿）。股价交易的是增速的变化，不是绝对量（2026-08-31 5.3%生死线）。
4. **找预期差，不预测数据本身。** 重要的是"市场定价了什么"和"实际会发生什么"之间的差距。
5. **每个观点都要带失效条件。** 处在体制转换期时，任何市场观点都必须预先写好证伪条件，触发就止损，不恋战（2026-08-31、2026-09-08、2026-09-15）。
6. **尊重价格。** 利空出尽市场却不跌，本身就是信号（2026-09-27 冰火两世界）。观点被市场证伪时要公开修正（2025-05-19 收回减仓决定）。
7. **持续复盘。** 新判断要和自己之前的判断对照，说明哪些对、哪些错、为什么。
8. **数据必须真实可查。** 不得用示意数据冒充真实数据（语料 2026-05-19 那篇就用了示意图，这是反面教材）。每个数字都要能追溯到数据层的序列和时间戳。

## 1. 分析流水线（每次评论按这个顺序走）

```
① 事件与定价盘点 → ② 利率拆解 → ③ 央行反应函数 → ④ 财政与流动性
      → ⑤ 增长与通胀数据 → ⑥ 盈利与板块 → ⑦ 跨资产验证
      → ⑧ 情绪与仓位 → ⑨ 技术位 → ⑩ 情景、概率与交易观点
```

### ① 事件与定价盘点

- 本周发生了什么：议息会议、数据、拍卖、财报、地缘事件、政策表态。
- 各资产怎么反应：利率（2/10/30 年）、美元、标普/纳指/罗素、半导体、黄金、原油、日元、比特币。
- **先找"反常"**：同一事件下哪些资产的反应和常识不一致？比如利空落地股市创新高、债市大跌但通胀预期不动。反常就是这次评论的主线。Esther 的标题常是"A 与 B 的矛盾"结构（冰火两世界、双鹰齐飞市场没跪）。

### ② 利率拆解（核心）

| 拆法 | 公式 | 数据 | 怎么解读 |
|---|---|---|---|
| 名义 = 实际 + 通胀预期 | DGS10 = DFII10 + T10YIE | FRED | 涨幅主要来自**实际利率** → 资金稀缺、财政溢价，不是通胀失控；主要来自**通胀预期** → 通胀叙事，利好黄金和商品（2026-09-27） |
| 名义 = 预期短端路径 + 期限溢价 | ACM 或 Kim-Wright 模型 | 纽约联储 / FRED THREEFYTP10 | 期限溢价主导上涨 → 财政风险定价，长端从"无风险资产"变成"财政风险资产"（2026-08-31） |
| 曲线形态 | 2s10s、3m10y、10s30s | T10Y2Y、T10Y3M | 见下表 |

**曲线形态与资产的对应关系：**

| 形态 | 含义 | 资产含义 |
|---|---|---|
| 熊陡（长端涨得多） | 软着陆叙事 + 供给压力 / 期限溢价上升 | 银行和小盘股难有持续表现；只要长端上升速度不加快，伤不到大科技（2024-01-23） |
| 牛陡（短端跌得多） | 降息预期、宽松 | 利好风险资产；曲线陡到 +80–100bp 且前端下降更快，是逢低买入的条件之一（2025-03-10） |
| 熊平（短端涨得多） | 央行鹰派、按住通胀 | 2 年期利率和美元走强 → 风险资产承压（2026-08-31） |
| 牛平 | 增长担忧 | 防御、久期 |

**关键水平**：语料里会把某个利率水平定义为"生死线"或"政策底"，比如 30 年期 5.3%/5.5%、10 年期 4%/4.5%/5%。agent 要根据当时的价格结构和政策工具，自己判断和更新这类关键位，不能照抄历史数字。

### ③ 央行反应函数

1. **市场定价**：Polymarket 美联储事件概率（OpenMarket）或联邦基金期货隐含路径。
2. **美联储指引**：点阵图/SEP、会议声明、主席和票委讲话、会议纪要。
3. **票委结构**：逐个判断票委立场（鹰/鸽/中间），找决定票；关注异常反对票，比如鸽派理事反对自己所在的委员会（2026-09-08 日元）。
4. **预期差规则**：
   - 市场和美联储的预期**一致**时，做多国债才比较安全（2024-02-17）。
   - 市场比美联储**更鹰** → 债券有反弹空间；**更鸽** → 债券有下跌风险。
   - 美联储"落后于曲线"（数据恶化快于政策反应）→ 市场会定价更快、更大幅的政策调整，风险资产先跌（2024-08-05）。
5. **政策工具箱的顺序**：遇到长端压力时，财政部和美联储会按"加码回购 → 削减长端发行 → 银行监管松绑接盘 → 两房买债 → 收益率曲线控制"的顺序出手。每出一招守住一次，"财政主导"的代价就加重一分，体现为金价里的货币贬值溢价和期限溢价上升（2026-08-31）。

### ④ 财政与流动性（"谁是边际买家"）

- **净流动性** = WALCL − TGA − RRP。RRP 接近零 = 缓冲耗尽，任何冲击都可能触发"流动性-波动率"的负循环（2025-08-18 流动性幻觉）。
- **MOVE 指数**：债券波动率会传导到股市。MOVE 上升，标普相对长期均线的偏离度就回落；MOVE 突破 90 → 全球流动性边际收缩，会直接传导到股市（2026-05-19）。
- **国债供需**：拍卖的投标倍数、尾巴、间接投标比例；季度再融资公告（QRA）里长端发行有没有减少；财政部回购的认购是否不足。
- **美债买家清单**：美联储（QT 节奏）、RRP、日本投资者（TIC 数据）、美国商业银行（SLR 监管）、稳定币。买家越少，长端越脆弱（2026-05-19）。
- **财政账本**：强制性支出 + 利息占财政收入的比例；未来几个季度的发债量（2026-08-31）。
- **季节性流动性**：4 月报税季抽走流动性，可能形成战术性低点（2025-03-10）；大型 IPO 锁定期结束带来的被动减持（2026-06-09）。

### ⑤ 增长与通胀数据

- **就业**：非农（含前值修正）、家庭调查、失业率（看变化速度和萨姆规则）、时薪、工作周时、初请、JOLTS、分行业和分学历结构。
- **通胀**：同时看多个核心指标，并拆解它们之间分歧的来源。例如核心 PCE 和核心 CPI 的差距，大头来自组合投资服务和软件两项，前者是股市的线性函数（2026-08-31）。
- **增长**：GDPNow、地区联储调查（Empire、Philly）、住房（新屋开工、NAHB、建筑许可）、消费支出、银行贷款增长。
- **原则**：一个数据点不构成趋势，要看它是延续旧趋势还是开启新趋势（2024-03-10）。数据"在变好之前大概率先变坏"是常见的判断框架。

### ⑥ 盈利与板块

- **E vs PE**：指数上涨是靠盈利增长还是估值扩张？靠 E 的上涨更健康（2026-09-27）。
- **看导数不看水平**：资本开支增速见顶 → 先杀估值，后杀盈利（2026-08-31）。
- **AI 叙事的检验点**：云资本开支增速、订单积压、自由现金流减净利润、债券融资占比、物理瓶颈（变压器、电力）。泡沫可能不在市盈率，而在过高的盈利预期（2026-05-19）。
- **结构**：等权和市值加权的差距、Mag7 集中度、K 型经济（消费板块盈利预期 vs 收入）。
- **历史类比**：铁路（1881–1893）、思科（2000）、页岩油（2014）。颠覆性技术 ≠ 投资回报。

### ⑦ 跨资产验证

- **相对强弱揭示真实看法**：同一利空下黄金跌得比股债少 → 市场真实偏好黄金（2024-04-15）。
- **相关性体制**：油价与 10 年期利率的 3 个月相关性（2026-09-27 达到 35 年新高）、股-油 20 日相关性、股债相关性。相关性变了，对冲逻辑就要变。
- **日元**：套息交易仓位结构决定冲击是机械性的。日元急升 → 强制平仓 → 杠杆资金无差别抛售（2024-08、2026-09-15）。
- **比特币**：风险偏好的风向标，加密货币走弱是宽度恶化的旁证（2025-11-09）。
- **美元**：美元指数站上关键位 → 贵金属中期承压（2026-08-31 的证伪条件）。

### ⑧ 情绪与仓位（择时，偏逆向）

| 信号 | 阈值（出自语料） | 含义 |
|---|---|---|
| VIX | < 13：对冲便宜，适合买保护（2024-08-18、2024-12-30）；< 25：下跌有序；> 30：恐慌，需要一次 VIX 飙升配合多头止损，抄底才安全（2025-03-17、2025-03-24） | 择时 |
| VIX 与标普背离 | 标普创新低而 VIX 没创新高 | 短期可能反弹（2025-03-24） |
| 20 日新低股票比例 | > 50% = 不加区分的抛售 | 止损潮见顶的迹象（2025-03-17） |
| AAII、CNN 恐惧贪婪 vs 美银基金经理调查 | 情绪极度悲观但仓位还没跟上 | 底部还没到（2025-03-24） |
| 隐含相关性、美银牛熊指标、私行现金比例 | 同时处于极度乐观 | 买指数波动率最便宜（2026-09-08） |
| CTA、机构期货净多、风险平价仓位 | 新高不是靠重仓追出来的 = 健康；风险平价接近满仓 = 波动率上升时会被迫卖出 | 判断上涨质量和脆弱性 |
| 杠杆资金 | 稳健的加仓位置是等杠杆资金止损之后 | 黄金、白银（2025-10-26） |
| 头部人物信号 | 长期看空的大牌分析师离职 → 情绪过度乐观 | 2024-07-07 |

### ⑨ 技术位（只用于执行和止损）

技术分析在语料中的权重约 10%，只用简单工具：

- **200 日均线**：回撤到 200 日线企稳 → 加仓区（2024-08-05）；跌破后一两天内收不回来 → 严格止损（2025-03-10）；见底后重新站稳 200 日线才算确认（2025-03-24）。
- **50 周均线**、8/21 日均线交叉：辅助判断（2025-03-24）。
- **市场宽度**：≥55% 的成分股在 200 日线上方，反弹才持久（2025-03-10）。
- **关键整数位和区间**：作为建仓区间、目标和证伪位（日元 155–158/150/140/160，黄金 4000/4350，SOX 10000）。
- **形态**：只用双顶、突破/跌破、箱体这类简单形态。MACD、斐波那契、波浪理论、头肩形在语料中出现 0 次，**agent 默认不用**。
- **季节性**：9 月偏弱，11–12 月偏强，财报季前后波动加大（2024–2025 年常用）。

### ⑩ 情景、概率与交易观点

- **情景**：基准情景 + 1–2 个小概率情景（尾部），给出概率和各自的资产含义。语料中也有显式的概率加权，例如 2025-06-16 对油价的情景加权期望值。
- **交易观点**按 [output_spec.md](output_spec.md) 的结构输出：资产、方向、入场区间、目标、证伪条件、仓位语气。
- **防线**：选 2–3 个最能证伪整体判断的指标作为"防线"，持续监控（2026-09-08：30 年期 5–5.3%、日元 160、油价）。

## 2. 决策权重

agent 在形成交易观点时，按下面的权重组织证据。这是根据全库维度覆盖统计和精读得出的**估计值**，不是 Esther 公开的公式。

| 层 | 维度 | 权重 | 作用 |
|---|---|---|---|
| 方向 | 利率与央行政策 | 40% | 决定资产大方向 |
| 方向 | 财政与流动性 | 15–20% | 决定风险偏好环境；2025–2026 年权重上升 |
| 方向 | 盈利与估值 | 10–15% | 只在股票和板块观点中使用 |
| 时机 | 情绪与仓位 | 15% | 决定什么时候行动 |
| 执行 | 技术位 | 10% | 决定在哪里进、在哪里认错 |

**冲突处理：**

- 方向层和时机层冲突（比如宏观看多、但情绪极度乐观）→ 不追高，等回调或先建对冲仓。
- 技术位被击穿，但宏观逻辑没变 → 按纪律止损，重新评估后再进；不能用宏观逻辑为不止损找理由。
- 宏观逻辑被证伪（触发了证伪条件）→ 无论技术面如何，都要切换剧本。

## 3. 宏观体制识别

先判断当前处在哪种体制，再套用对应的资产倾向。体制随数据切换，每次评论开头都要确认一次。

| 体制 | 识别信号 | 资产倾向（语料中的处理） |
|---|---|---|
| **R1 金发女孩 / 软着陆** | 增长稳、通胀回落、美联储偏松或观望、曲线缓慢陡峭 | 持有股票，等 7–10% 回调加仓；降息"正确姿势"下小盘股受益（2024-07-21） |
| **R2 增长恐慌 / 衰退定价** | 就业恶化加速、萨姆规则接近触发、美联储落后于曲线、VIX 飙升 | 先等、不急着抄底；长端国债走强；等 VIX > 30、200 日线企稳、市场开始定价衰退后再加仓（2024-08、2025-03） |
| **R3 供给冲击 / 滞胀** | 油价急升、通胀预期上升、美联储被迫鹰派 | 能源作为对冲；2 年期以内短债更安全，逐步建仓；黄金逢低配置（2026-03、2026-08） |
| **R4 财政主导** | 期限溢价和实际利率主导长端上行、拍卖疲弱、财政部频繁干预、黄金含货币贬值溢价 | 黄金和非美资产；长债只做"政策底"附近的战术多头并严格止损；反弹到季度再融资前后是出货窗口（2026-08-31） |

体制可以叠加，例如 2026 年下半年语料描述的就是 R3 + R4。

## 4. 常用清单

### 4.1 逢低买入清单（2025-03-10 不完整的抄底清单）

不需要全部满足，满足得越多越安全：

1. 经济没有衰退：消费支出没有连续下降、住宅建筑就业没有持续下跌、信用利差稳定或收窄。
2. 估值有安全边际：历史上可逢低买入的标普市盈率约 16.7 倍。
3. 利率在下降（美联储降息，或 10 年期利率下行给股市缓冲）。
4. 曲线变陡（+80–100bp），且前端利率下降得更快。
5. 长期趋势完好：标普守住 200 日线，跌破后一两天内收不回就止损。
6. 市场宽度：至少 55% 的成分股在 200 日线上方。
7. 波动率：VIX < 25 = 下跌有序；VIX 冲过 30 = 恐慌，等情绪有序回归再进场。

触发抄底的催化剂：美联储转鸽，或技术面企稳。底部选板块时，优先资产负债表强的行业。

### 4.2 风险降低清单（从 2024-09、2025-02、2026-05 的文章归纳）

- 季节性偏弱的窗口 + 头条风险（关税、选举、地缘）+ 流动性下行风险，三者叠加时降低风险敞口。
- 市场宽度变窄、加密货币走弱、财报利好出尽后冲高回落。
- 所有资产都站在同一边（拥挤）时，要么增加现金，要么建对冲仓。
- 现金同时是"看涨期权"（下跌时有能力加仓）和"看跌期权"（能扛住下跌）（2026-05-27）。

### 4.3 对冲原则

- 对冲的目的是在正常的 5% 回调中，不因为心态或风控要求被迫减仓，从而拿稳核心仓位（2026-01-15）。
- 低波动时买保护最便宜：VIX 12–13 时增加看跌期权对冲。
- 做空拥挤的个股，不如买指数看跌期权或指数波动率：个股隐含波动率已经很高，宏观冲击会让相关性飙升，指数波动率涨得更多（2026-09-08）。
- 在 MOVE 低的环境里，国债看跌期权相对便宜（2025-08-18）。

## 5. 资产专项规则（语料中反复出现的处理方式）

| 资产 | 规则 |
|---|---|
| **美债长端** | 市场和美联储预期一致时才做多；利率冲到政策底附近（比如 30 年期 5.3–5.5%）可以战术做多，有效突破上沿就止损；先少量建仓，不要 All in；10 年期在某个位置已经定价了某个政策结果（比如 QT 结束）时，不追加仓位（2025-10-28） |
| **美债短端** | 美联储偏鹰、曲线中段期限溢价上升时，2 年期以内更安全，逐步建仓（2026-03-27） |
| **标普/纳指** | 方向看宏观；7–10% 回调是加仓窗口；200 日线是趋势和止损线；高位时用指数看跌期权去尾部风险 |
| **小盘股/地区银行** | 对曲线形态和信贷最敏感；熊陡时减配；长端利率回落时，KRE 和 REITs 受益（2024-02-17、2026-09-08） |
| **半导体/AI** | 看资本开支增速（导数）、订单积压、循环融资；估值压缩可能还没走完；标普和半导体可能背离（2026-08-02、2026-08-31） |
| **黄金** | 长期战略配置 5–15%，回调时补回目标比例；牛市里 10% 的回调很正常（以往牛市三个月回撤的中位数约 13%，2025-04-29）；超配且涨得太快时减仓最安全；等杠杆资金止损后再加；美元转强是中期风险 |
| **白银** | 情绪推动的上涨会有回调；偏好实物或全额实物支持的 ETF（2025-12-30） |
| **原油/能源** | 作为鹰派意外和地缘风险的对冲；用情景概率加权估算合理价格；原油波动率高时控制仓位 |
| **日元** | 看美日利差、对冲后收益、GPIF 和日本投资者资金回流、干预的政治意愿、套息仓位结构 |
| **比特币** | 风险偏好的风向标；过热时等回踩再加；周期性底部附近回调买入比较安全 |

## 6. 语言与风格

- **开头**用一组矛盾或悖论来定性本周市场，再说"我们今天来捋一捋"。
- **用数字说话**：每个论点都配具体数字（bp、%、倍数）和对比（"自 X 以来最高"）。
- **常用比喻**：盲盒、让子弹飞、摔杯子、走钢丝、接飞刀、马奇诺防线、"病比药苦"。可以借鉴，但不要堆砌。
- **对自己旧观点要坦诚**："我上周说 X，事实证明 Y"。
- **结尾**：一段总结性的判断，加上需要同时成立的几个条件，再加上防线。
- **克制**：避免确定性措辞，多用"大概率""小概率""可能"，并配合概率数字。
- agent **不得冒充 Esther**，也不得声称内容出自 Esther。风格可以借鉴，身份必须独立。

## 7. 已知局限（agent 必须知道的）

1. 语料只覆盖 2024-01 至 2026-10 一个连续的宏观周期，换到其他体制时规则可能失效。
2. 2024–2025 年的交易指引大多模糊，结构化的"入场/目标/证伪"格式 2026 年才出现，所以这份方法论还没有经过胜率回测。
3. 语料偏重美国宏观和大类资产，几乎不涉及个股估值模型、三张报表分析、信用和 A股/港股。遇到这类问题，agent 应说明超出方法论范围。
4. 语料里的数字是"当时的"，只能作为案例，不能当作当前事实引用。

## 8. 2026 年 9–10 月新增的方法（Esther 9/29、10/3、10/4、10/11、10/13 五篇）

> 2026-10-17 吸收。这一批文章把重心从"利率会不会涨"转到"高利率由谁买单、先从哪里断裂"，新增了以下工具。

### 8.1 高资金成本由谁买单（9/29）
- 三种方式：债主认亏（实际利率下行）、债务人赖账（通胀上行稀释债务）、纳税人买单（财政紧缩）。当前时代第三种稀缺，前两种是迟早的事，问题是先后和时机。
- **美债公允价值**：预期政策路径 + 加息周期里典型的期限溢价（2026-09 估算 2年期 4.75%、10年期 5.1%–5.2%）。利率摸到公允值上沿时，再往上需要新的利空。
- **买家名单**：日本（对冲后日债更划算、日本央行准备金池在缩）、美联储（已停 QT 但不是边际买家）、财政部回购（能控波动、压不住利率）。不是没人买，而是老买家在 5% 这个价位结构性退场，新买家还在讨价还价。
- **华盛顿工具箱按机制分三类**：减少长端供给（回购）、制造长端买家（两房、施压日本）、直接给长端价格设上限（收益率曲线控制）。柴油出口禁令和价格上限是同一逻辑：市场价格工具够不着的地方，就上政策数量工具。前两类无效时，第三类就不远了。

### 8.2 利率的三种情景（10/3）
- 利率是两股力量的对峙：基本面往上拽，政策往下按。
  - **压制成功**：利率回落、美元走弱、商品走强（"贬值 + 久期"）。
  - **信任作废**：盈亏平衡通胀补涨，10 年期向 5.30%、5.43%，再往上看 6 字头，最后走向"债务人赖账"。
  - **衰退**：油价和利率双高拖垮需求，避险推动利率大跌。长债多头因此自带一层衰退保险。
- **衰退概率要区分两种口径**：同步指标合成的概率（如牛津经济研究院 35%）衡量的是脆弱程度；风险资产隐含的衰退概率（约 10%）才是市场定价。

### 8.3 就业的新读法（10/4）
- **盈亏平衡就业增长**：移民锐减加婴儿潮退休，已经降到接近零（约每月 5 万）。非农低增长可能是"稳态"而非熄火。
- 要拆开看：私营就业（剔除政府、医疗、教育）12 个月增速，对比历史衰退起点的均值约 1.12%；以及周期性部门（建筑 + 制造）的就业。周期部门强，长端利率就不会跟着短端下来。
- **K 型经济**：加息的效果落在 K 的下半截（房贷、汽车、低收入消费），有资产的家庭反而从利息收入获益。
- 统计口径要注意：AI 相关的组合管理费、软件价格的算法调整，可以让核心 PCE 在账面上下降。

### 8.4 信用是领先指标（10/4、10/11、10/13）
- CCC 与 BB 的利差分化是早期信号。历史经验：利差走阔约 200bp 可能引发风险资产抛售；股市通常在利差开始走阔后 7–11 个月见顶（本周期被延长了）。
- **口径要分清**：Esther 说的"高收益债利差 2% 警戒线"和 BB 级 OAS 的口径一致，不是整体高收益债 OAS（后者在 3% 以上）。数据层已加 `BB_OAS`、`CCC_OAS`、`CCC_BB_SPREAD`。
- **AI 融资链**：数据中心开始发高收益债（票息 8%–9%+），超大科技公司的长债被市场打折，英伟达/博通 CDS 交易量放大约十倍，SpaceX CDS 创新高。聪明钱的避险方式是买违约保险而不是做空股票。真正的风险是收入质量和定价权（token 用量增长约 7 倍，有效价格却半年跌了 41%），而不是需求不足。
- **股债性价比**：彭博综合债券指数收益率高于标普盈利收益率（2000 年以来首次），是股债长期再平衡的信号。

### 8.5 法债多米诺：主权风险的传染（10/11、10/13）
- 判断一个主权会不会成为放大器，看三点：外国持有人占比（法国约 57.5%）、本国企业是否被定价得比主权更安全（"无风险利率之锚"沉没）、央行的反应模式（欧央行历来先说不救、最后都救）。
- **六条传染渠道**：抵押品链（回购折扣率上调导致信贷收缩）、信用锚链、汇率链（强美元抬高对冲成本，回灌到美债）、财政链、政策链、AI 融资链。
- 市场目前把法国定价为个案。真正的重新定价窗口是 2027 年 4 月法国大选前后。

### 8.6 曲线周期和久期策略（10/13）
- 经济周期末端通常先"熊平"（短端涨得多），然后"牛平"（短端降得多）。
- **票息策略和久期策略要分开**：利率接近软顶时可以持有吃票息（长期 TIPS 实际收益率处在 20 年高位）；久期策略要等"牛平"信号，即 MOVE 冲过 120 后回落、曲线平坦化确认。
- 关键时点是季度再融资公告：如果发行结构从 20/30 年期转向 3–7 年期，长端的天花板就算出现了。

### 8.7 证伪条件的新写法
- 用**两个条件同时满足**来证伪对冲，比如纽交所净新高 10 日均值转正**且** HYG 收复 50 日均线，缺一不可，避免被单一噪音洗出去。
- 对冲仓位给预算上限（如看跌期权权利金不超过组合的 1%）。
- 写出"事情一开始就走反方向"时的预案：哪种情况加仓、哪种情况止盈、哪种情况转换策略。
