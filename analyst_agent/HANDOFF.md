## 1. 这是什么

`bold-euclid/analyst_agent/` 是一个**只在本地自用**的宏观策略分析 agent。它没有服务端，也没有界面：由 IDE 里的 AI 助手直接扮演 agent，读取本地的方法论文件和数据快照，按固定流程输出分析。

- **视角 A（Esther）**：美国宏观 → 利率 → 风险资产 → 执行。来源是 Esther 的 Substack（扬缨），2024-01 至 2026-10，共 295 篇中文。
- **视角 B（Brooks）**：全球宏观 → 外汇 → 主权债务。来源是 Robin Brooks 的 Substack，2026-01 至 2026-10，共 305 篇英文。
- **已做出的决定**：
  - 2026-10-03 放弃把它做成公开网站，不要再提议部署；
  - 2026-10-14 代码已提交进 GitHub 仓库（PR #25）；
  - `data_layer/cache/` 和 `snapshots/` 已加入 .gitignore。

## 3. 怎么运行

```bash
node analyst_agent/data_layer/fetch_snapshot.js                      # 今天的快照
node analyst_agent/data_layer/fetch_snapshot.js --asof 2026-09-25    # 历史某天，序列在那天截断
node analyst_agent/data_layer/fetch_snapshot.js --event 2026-02-27   # 计算"自某事件以来"的变化
node analyst_agent/data_layer/fetch_snapshot.js --lens esther        # 只拉某个视角的指标
node --test test/analyst_snapshot.test.js
```

- 项目是零依赖的 Node（≥18），不需要安装任何 npm 包。
- 数据源都免费、不需要 key：FRED 的 CSV 接口、Yahoo 的 chart 接口（非官方，偶尔会被限流，有重试）、美国财政部 FiscalData。
- 最近一次快照（2026-10-19）：98 个指标，成功 92 个，6 个需要人工补充或运行时读取。
- **OpenMarket MCP**：用来读 Polymarket 上的美联储利率概率，以及 Hyperliquid 永续合约的 7×24 价格。Free 档只有 7 天 K 线。**目前需要重新授权**，最近几次都没读到。

## 4. 工作方式（摘自 AGENT.md，以原文为准）

**四种模式：**
1. **文章点评**：用户贴正文或网址。网址用网页抓取工具读；X 或 Medium 抓不到时，用浏览器打开读。
2. **周报**：完整流程。
3. **单点问答**：比如"日元怎么看"。
4. **复盘**：对照最新数据逐条检查台账。

**每次分析前：**
- 检查快照是不是今天的（周末可以放宽到上一个交易日之后），不是就先刷新；
- 读 `.md` 快照；
- 需要时读 OpenMarket；
- 快照里标"待人工补充"的数据，直接问用户要。

**输出的硬性规则：**
- **数字只能来自快照、OpenMarket 或用户提供的材料**，不编造；历史对比必须有数据支持。
- 先做定价拆解（实际利率加通胀预期、期限溢价、10y10y 远期、美联储概率、油价隐含中断、汇率对利差），再给方向。
- 两个视角分歧时：把两边都写出来，指出能裁决的数据，仓位最多"少量试仓"。
- 每个交易观点都要有可量化的证伪条件；写入 `ledger/views.jsonl`。外部人士的观点也记进去，标为 `"mode":"external"`。
- 不用 MACD、斐波那契、波浪理论。不冒充 Esther 或 Brooks。过滤掉政策主张和价值判断。
- 结尾附一句："仅供个人研究，不构成投资建议"。
- 语料里的数字都是"当时的"，只能参考推理方式，不能当作当前事实引用。
