# UI / 交互设计审核（2026-11-27）

> 范围：本地实机（`node server/index.js`）1440×900 夜间、375×812 日间，8 个视图逐一走查；对照 5 个同类产品。
> 结论先行：**信息架构、数据可信度信号与美学辨识度已达到或超过同类**；短板集中在**排版可读性、图表工具、首屏全局概览和动效时长**。本次在不改动 Atelier 视觉语言的前提下落实了 9 项改进，另列 8 项后续建议。

## 1. 参考案例与可借鉴的做法

| 产品 | 看了什么 | 可借鉴 |
|---|---|---|
| [Velo](https://velo.xyz/futures) | 期货面板（实机） | 顶部一个资产搜索 + 时间窗作用于全部图；**每张图自带工具条**（刷新、重置、导出、全屏）；图卡尺寸统一 |
| [The Block Data](https://www.theblock.co/data/options) | 期权数据页（实机） | KPI 卡「大数字 + 24h 变化」；图下脚注「来源 · 更新时间 · 打开完整图表」 |
| [Artemis](https://app.artemis.xyz/home) | 首页（实机） | 图标轨导航带文字标签；`Ctrl K` 全局搜索；**顶部行情条常驻** |
| [Delphi Digital 期权看板](https://members.delphidigital.io/feed/new-tool-on-the-delphi-portal-cross-venue-options-dashboard) | 据其门户公告与 [Crypto Briefing](https://cryptobriefing.com/delphi-options-dashboard-crypto-launch/) 报道，未实机查看 | **首行放市场 KPI**；五个场所合并；60 秒刷新 |
| [Glassnode Studio](https://glassnode.com/products/studio) | 据 [官方 changelog](https://docs.glassnode.com/further-information/changelog/2025) 与文档 | 仪表盘可加注释、可链接分享；图表页与仪表盘页侧栏统一 |

通用原则（来自 [Toptal](https://www.toptal.com/designers/data-visualization/dashboard-design-best-practices)、[UXPin](https://www.uxpin.com/studio/blog/dashboard-design/) 等设计指南，属经验总结而非一手研究）：五秒内抓到要点；主要信息在前、次要信息折叠（渐进披露）；时间戳与来源是可信度的一部分；受众越专业，可承受的密度越高。

## 2. 八个维度的评估

评分 1–5；箭头表示本次改动后的状态。

| 维度 | 评分 | 现状与证据 |
|---|---|---|
| ① 信息架构与导航 | 4 | 侧栏二级目录 + 单模块聚焦 + `#view/module` 深链 + `Ctrl K` 命令面板，已接近 Artemis / Glassnode。**缺口：没有跨模块的一眼概览**——每个视图一次只显示一张卡，判断"今天市场处在什么状态"要点开 8 个视图。 |
| ② 信息密度与层级 | 3 | 每张卡以一句结论开头（符合"信号 → 上下文 → 下一步"）。但头图每页约 200px 只重复侧栏标题；部分视图文字量极大（大宗 ≈ 4.1 万字、期权 ≈ 1.9 万字、基差 ≈ 1.5 万字），长段"研判"排在图前。 |
| ③ 排版与可读性 | 2 → 4 | 改前 CSS 有 **117 条规则字号 < 11px**（9.6–10.9px）；期权视图单页 **147 处**文字小于 11px；**20 处** KPI 副标题被单行省略截断（截掉了"全成交校正"等关键口径）；数字只有 4 处用了等宽，实时刷新时数字左右跳动。 |
| ④ 数据可信度信号 | 5 | 每张卡「正常 · 数据时间 · 最后成功」、健康监测、降级横幅、口径折叠说明，比 The Block 的"来源 · 更新"脚注更细。唯一问题：降级消息很长，直接压在 ASCII 叠层上。 |
| ⑤ 图表交互 | 3 → 4 | 已有 dataZoom、轴联动、图例开关。**缺每张图的全屏与导出**（Velo、The Block 都有，只有全局截图）。ECharts / Chart.js / Lightweight Charts 三套库并存，tooltip 与操作不统一。 |
| ⑥ 动效与性能 | 3 → 4 | 改前每次切换视图入场约 **1.5 秒**（卡片 0.85s + 错峰最多 0.64s；瓷砖 0.7s + 最多 0.74s；标题逐字 0.8s）。ASCII 叠层常驻动画；`app.js` 450 KB 未压缩 + `echarts.min.js` 1 MB 全量。已尊重 `prefers-reduced-motion`。 |
| ⑦ 响应式与可访问性 | 3 → 3.5 | 手机底部导航、横滑瓷砖已做。**顶栏本应吸顶**（有"滚动后浮起玻璃底"逻辑），却被 Atelier 层第 2 节的 `position: relative` 覆盖，长页面里 BTC 价格、`Ctrl K`、刷新入口会滚走。`focus-visible` 只在 Atelier 层有 9 处。 |
| ⑧ 美学辨识度 | 5 | 油画舞台 + ASCII + 衬线大标题，在几乎清一色"Inter + 深色网格"的同类里独一份，与立意一致。**保留**。冲突只出现在画作与数据争同一块屏幕的地方：状态条、头图。 |

## 3. 本次已落实

全部改在 `public/atelier.css`（第 17 节）、`public/style.css`（字号下限）、`public/atelier.js`，以及新文件 `public/chart_tools.js`（由 `atelier.js` 动态加载，所以不需要改 `index.html`）。

| # | 改动 | 对应维度 | 细节 |
|---|---|---|---|
| 1 | **市场读数条** | ① ② | 头图标题下一行 8 个读数：1M ATM IV、25Δ Skew 30D、Gamma 翻转、90D 基差、永续资金费、mNAV、STRC、麦克莱伦 Core。直接镜像各模块已渲染的元素（MutationObserver），**不发新请求**；点击跳到对应模块；当前模块高亮；数值变化时短暂高亮（减少动效时关闭）。手机上横滑。 |
| 2 | **图表工具条** | ⑤ | 悬停任一 ECharts 图右上角出现 放大 / 导出 PNG / 导出 CSV。放大是页内浮层而非浏览器原生全屏（内嵌浏览器和 iPhone Safari 不支持元素级全屏；卡片的 backdrop-filter 又会困住 fixed 定位，所以把图节点临时移到 body 下的浮层，原位留等高占位，Esc 或点空白处放回）。CSV 把图上全部序列摊成宽表，带 BOM（Excel 中文不乱码），时间轴按 UTC+8；迷你图、仪表与弹窗里的图不加；触屏设备隐藏。 |
| 3 | **字号下限 11px** | ③ | `style.css` 96 条、`atelier.css` 22 条低于 11px 的规则抬到 11px；卡片角标（拉丁等宽大写 + 字距，装饰性）保留原尺寸。期权视图 < 11px 的文字 147 → 5（只剩角标）。 |
| 4 | **数字等宽** | ③ | `body { font-variant-numeric: tabular-nums }`，刷新时数字不再跳，表格列对齐。 |
| 5 | **KPI 副标题两行 + 悬停看全文** | ③ | `.m-sub` 由单行省略改为最多两行；任何被省略号或行数截断的元素，悬停时自动补上全文 `title`。 |
| 6 | **三列卡片内瓷砖自适应** | ③ | 期权视图三卡并排时瓷砖不再溢出卡片右缘（`auto-fit` + `min-width: 0`）。 |
| 7 | **状态条可读** | ④ ⑧ | 状态消息与时间戳各放进玻璃胶囊，保持一行，过长省略、悬停看全文。 |
| 8 | **顶栏恢复吸顶** | ⑦ | `.app-header { position: sticky }`，原有"滚动后浮起玻璃底"随之生效。 |
| 9 | **入场动效缩短** | ⑥ | 卡片 0.85s → 0.5s、错峰 80 → 45ms；瓷砖 0.7s → 0.38s、错峰 32 → 16ms；标题逐字 0.8s → 0.5s、每字 26 → 14ms。视图切换总时长约 1.5s → 0.85s，风格不变。 |

## 4. 后续建议（未做）

**P1**

1. **读数条的指标由你来定**。现在 8 项是按"原创、可检验"的选题标准挑的初稿；若要加"较昨日变化"，需要各模块把前值暴露出来，而不是只镜像显示文本。
2. **长篇研判分层**：大宗、基差两个视图仿照已有的 dealer / skew 三层简报（结论一句 → 依据 → 口径），把长段落折到图后面。
3. **非 ECharts 图接入工具条**：宏观图（Chart.js）、波浪引擎（Lightweight Charts）还没有全屏 / 导出。更彻底的做法是把宏观图迁到 ECharts，去掉 `chart.min.js`（208 KB）。
4. **模块聚焦时的头图**：现在的大标题重复侧栏一级标题；聚焦单个模块时可改显示模块名，或整体压低到 1.6rem，把首屏让给数据。

**P2**

5. **性能**：`app.js` 按视图拆分懒加载；ECharts 自定义构建（只打包实际用到的 line / bar / scatter / heatmap / gauge 与 dataZoom / tooltip / legend / markLine），体积可明显小于现在的 1 MB 全量包；ASCII 叠层在标签页隐藏或快速滚动时降帧。
6. **全局时间窗**（Velo 式）：现在每张卡各有一套 3M / 6M / 1Y / ALL，可加一个全局选择器统一驱动，卡内保留覆盖。
7. **可访问性**：`style.css` 层补 `focus-visible`；涨跌除颜色外加符号或箭头（色弱可辨）。
8. **内联小字号**：`index.html` 与 `app.js` 模板字符串里写死的 `font-size` 未处理（本次只动了样式表）。
